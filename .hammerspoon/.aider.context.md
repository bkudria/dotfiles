This is Hammerspoon configuration, in ~/.hammerspoon. It bootstraps with init.lua, which loads `yue`, a language called YueScript, which compiles to Lua. The main Hammerspoon configuration starts with index.yue

Background: 
 - YueScript is a Lua dialect offering expressive, concise syntax. It is heavily based on `moonscript`, so that tag can be used when outputting code blocks for better syntax highlighting.
    - Usage: In this configuration, YueScript is used to write the main script (index.yue), enhancing readability and maintainability.
    - Features Utilized:
       - Module System: Using require and import to manage modules.
       - Functions and Lambdas: Defining functions with concise syntax.
       - Metaprogramming: Leveraging macros and advanced features for code generation and manipulation.

1. init.lua
- Purpose: Entry point for Hammerspoon, setting up the environment and loading configurations.
- Key Components:
  - Enhanced Logging: Redefines print for improved console output with timestamps and formatting.
  - LuaRocks Integration: Configures Lua package paths to include LuaRocks modules.
    - Window Filter Workaround: Ignores certain "Web Content" windows to fix known issues.
    - YueScript Configuration Loading: Uses require("yue")("index") to load index.yue.
    - Performance Logging: Measures and logs execution times of initialization steps.

2. index.yue
 - Purpose: Main Hammerspoon configuration script, written in YueScript for expressive syntax.
 - Key Components:
    - Global Utilities:
       - p: For printing inspected values (debugging).
       - timeDeltaFrom: Calculates time differences (performance logging).
    - Module Imports and Initialization:
       - Modules like loader, clock, flux, screens, cloak, extensions, apps, typer, clipper, paster, Hyper, dispatch, deck.
       - Uses a timed function to measure and log initialization times.
    - Hyper Key Configuration:
       - Extensive keyboard shortcuts using the Hyper key.
       - Keybindings: Launch apps, control windows, manipulate text, system controls.
       - Nested Menus: For complex actions within Hyper key mappings.
    - Siri Remote Configuration:
       - Maps Siri Remote buttons to Hammerspoon actions (e.g., media controls, navigation).
    - Extension Initialization:
       - Starts extensions like Seal with custom configurations.
    - URL Handling:
       - Sets up Hammerspoon to handle HTTP URLs, opening them in Chrome.
    - Performance Logging:
       - Logs execution times for each configuration step and total time.
