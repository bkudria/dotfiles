This is Hammerspoon configuration, in ~/.hammerspoon. It bootstraps with init.lua, which loads `yue`, a language called
YueScript, which compiles to Lua. The main Hammerspoon configuration starts with index.yue

Background: 
- Hammerspoon ("HS") is a tool that allows automating macOS by providing Lua APIs to aspects of the system, as well a large set of other functionality
  - Documentation for any part of the hammerspoon API can be accessed by running `hs -c "help.identifier"` where `identifier` is replaced by the API component documentation is needed for. For example, `hs -c "help.hs"` will list core Hammerspoon functions and modules.
  - Methods are documented by how they're called with the Lua `:` syntax (e.g. `hs.window:id()`) but the identifier for method documentation uses the plain dot notation (e.g. the docs would be found using `help.hs.window.id`)
  - Always ask to get the documentation for any Hammerspoon functions in code you are working with.
  - You can also access Lua documentation using the `lua` prefix instead of `hs`.
  - For example, file APIs are found under `help.lua.file`. The identifier `lua._man` provides the table of contents for the Lua 5.3 manual. You can pull up a specific section of the lua manual by including the chapter (and subsection) like this: `lua._man._3_4_8`.
  - Spoons are third-party extensions and libraries provided by other users. Their documentation, if any, can be found under `help.spoon`
   
 - YueScript is a Lua dialect offering expressive, concise syntax.  
   - In this configuration, YueScript is used to write the main script (index.yue), enhancing readability and maintainability.
   - Yuescript is heavily based on `moonscript`, so triple-backtick code-blocks can be tagged with `moonscript` for better syntax highlighting, as `yuescript` is not yet supported for highlighting.
   - Documentation for Yuescript is included, please study it carefully
   - Yuescript syntax is whitespace-significant

Files:

init.lua
- Purpose: Entry point for Hammerspoon, setting up the environment and loading configurations. Written in Lua
- Key parts:
  - LuaRocks Integration: Configures Lua package paths to include LuaRocks modules.
  - Yuescript Configuration Loading: Uses require("yue")("index") to load index.yue.

index.yue
- Purpose: Main Hammerspoon configuration, written in Yuescript for expressive syntax.
  - initializes, loads, starts, and/or configures all functionality. Other Yuescript files are used to do so, starting with `drive.yue`
  - Other components
    - Siri Remote Configuration:
       - Maps Siri Remote buttons to Hammerspoon actions (e.g., media controls, navigation).
    - Extension configuration:
       - Starts Spoons like Seal with custom configurations.
    - URL Handling:
       - Sets up Hammerspoon to handle HTTP URLs, opening them in Chrome.
    - Performance Logging:
       - Logs execution times for each configuration step and total time.
  - HS APIs:

    - hs.eventtap.keyStroke

drive.yue
  - The Drive class underpins a large part of the configuration, and provides core functionality for almost all other modules (or "drives")
    - Functionality:
      - Lifecycle Management: Methods like new, start, stop, and restart, with placeholders (beforeNew, onNew, afterNew, etc.) for custom behavior during initialization, starting, and stopping.
      - State Management: Utilizes hs.watchable for watchable state variables and hs.settings for persistent state across restarts.
      - Logging Utilities: Initializes a logger for each drive using hs.logger, facilitating consistent logging with drive-specific names or icons.
      - State Watching: Provides methods like watchState and getState to watch for state changes and retrieve state values.
    - HS APIs:
      - hs.logger.new
      - hs.openConsole
      - hs.settings.get
      - hs.settings.set
      - hs.timer.absoluteTime
      - hs.watchable.new
      - hs.watchable.watch
